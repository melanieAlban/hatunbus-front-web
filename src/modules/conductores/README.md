# Módulo Conductores

Estructura del módulo `conductores` (frontend). Contiene interfaces, servicios, store, componentes y vistas para gestionar conductores.

Endpoints esperados en backend:
- `GET /api/conductores/cooperativa/{id}`
- `GET /api/conductores/cooperativa/{id}/activos`
- `GET /api/conductores/{id}`
- `POST /api/conductores`
- `PUT /api/conductores/{id}`
- `DELETE /api/conductores/{id}`
- `PATCH /api/conductores/{id}/desactivar`

Esta carpeta contiene implementaciones base y ejemplos para integrarlo con el resto de la aplicación.
